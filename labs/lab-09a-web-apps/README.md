# AZ-104 Labs - Lab 09a: Implement Web Apps

## Objetivo
Configurar una aplicación web para mostrar una aplicación "Hola Mundo" en un repositorio externo de GitHub. Crear un entorno de pruebas e intercambiarlo con el entorno de producción. Aprender sobre el escalado automático para adaptarse a los cambios en la demanda
